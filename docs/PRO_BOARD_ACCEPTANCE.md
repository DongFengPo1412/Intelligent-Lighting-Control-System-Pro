# Pro 首次实机验收（2026-11-05，待部署）

本轮范围由用户最后要求收敛：先电脑网页，后手机 APK；100款均提供简短游玩说明，贪吃蛇采用撞墙失败的经典规则。手势与语音游戏控制属于后续可选扩展，不作为本次100款收尾门槛。不再以补齐所有额外关卡、专属音效或难度认证为首次部署的前置条件。

## 软件交付与证据边界

- 统一页面增加 `arcade_game_guides.js`：按正式 Target ID 提供100份操作与目标，选卡可预览，进入后显示完整说明；APK从同一源目录打包。旧归档游戏编号不得用来编写说明。
- 正式 #033 源码原本已默认撞墙失败；本轮修复旧灯效菜单的贪吃蛇穿墙行为，增加实际 C++ GameEngine 的四面墙、食物成长、身体碰撞、重开和倒车保护测试。
- 保留 Amadeus、世界线及红莉栖既有美术，整理选卡卡片、说明区和响应式排版。浏览器画面属于软件预览，不是灯板视觉验收。
- 游戏通用声音、专属动作声音、完整成功路径与实体体验仍分别记录；原有验收数字不因本轮简介或构建而自动提高。

## 已连接板卡与部署约束

只读识别为 ESP32-S3、16MB Flash、8MB PSRAM，Secure Boot / Flash Encryption 均未启用。当前旧分区表为 `nvs:0x9000/0x6000`、`phy_init:0xf000/0x1000`、`factory:0x10000/0x100000`。它不同于新版双OTA表，不能直接只刷 App，也不能用新表的地址解释旧数据。

私有备份、校验和、串口日志和构建产物位于任务专属缓存/工件，不进入版本库。以该次实际生成的备份清单为准；读取失败不算完成，备份校验不等于恢复已实测。

部署需单独取得用户明确授权：确认全部实际写入范围均已有可核验原件，保留 NVS，核对 ESP-IDF `flasher_args.json` 的引导程序、分区表、OTA初始化数据与 App 地址；不执行全片擦除。首轮不写备用 OTA App 和 storage，不擅自修改 OTA 分区设计。串口错误不能跳过镜像回读/工具校验，失败时停止并保留日志。

## 按顺序进行，逐项等用户反馈

| 顺序 | 实际检查 | 通过条件与停止条件 |
| --- | --- | --- |
| 0 | 备份、授权、部署与启动 | 校验实际写入镜像，采集启动堆/PSRAM/栈和显示/UDP/音频任务日志；没有重启循环、分配失败或缺失关键任务。发现问题先修复，不扩大验收。 |
