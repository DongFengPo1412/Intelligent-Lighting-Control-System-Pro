## 必要的兼容运行配置与安全降级

本机共享 `ai_cv_env` 的原始配置不能直接沿用：`transformers==4.46.3` 要求 `huggingface-hub>=0.23.2,<1.0`，而共享环境安装了 `huggingface-hub==2.4.0`。本轮只在任务缓存 `C:\Users\Liu\.codex\cache\tasks\20261105-pro-final-audit\runtime-overlay` 中安装 `huggingface-hub==0.36.0`，没有修改共享环境或替换角色权重。兼容约束记录在 [requirements-voice-constraints.txt](../pc-agent-vision/requirements-voice-constraints.txt)；该文件不是完整语音环境安装器。

默认 GPU/cuDNN 路径出现过真实 native abort，不能由 Python 异常降级保证恢复。本轮经过真实组件验证的配置必须显式满足：

- 使用 Python 3.10 与上述隔离依赖覆盖，使实际解析到的版本为 `transformers==4.46.3`、`huggingface-hub==0.36.0`。
- `KURISU_AUDIO_TRANSPORT=wifi`、`KURISU_ASR_DEVICE=cpu`、`KURISU_TTS_CUDNN=0`。ASR 使用 CPU；TTS 保留 CUDA，仅关闭其进程中的 cuDNN 路径。没有宣称修复共享 GPU 库或恢复默认 GPU ASR。
- 聊天、翻译的端点配置保持一致。`OPENAI_BASE_URL` 与翻译使用的 `KURISU_API_BASE` / `OLLAMA_HOST` 不能解析到不同服务；[部署配置检查](../scripts/pro_deployment_preflight.py) 会拒绝不一致配置。
- 现有 KWS、Whisper、角色 TTS、BERT/HuBERT 和参考音频资源仍为外部运行依赖，不随源码或模拟模式自动获得。

本轮真实生产 `VoiceListener` 初始化与 `VoiceEngine` 先中文、后日文的 PCM/WAV 生成已通过；证据为任务缓存中的 `real_voice_production_profile.log` 和 `real_voice_production_profile.json`。记录包含真实 KWS/Whisper 加载、静音未唤醒/未转写，以及角色 TTS 生成非空双语音频。没有播放、连接设备或从真实麦克风采音，不能据此证明音色、识别率、完整对话体验或无线播放质量。

配置检查只确认版本、设置和资源存在性；真实组件测试只证明所记录配置与样例。缺少模型/语音依赖、翻译或合成失败时仍须明确报告并静音；控制操作没有板端 ACK 时不得播报成功。模拟器、Mock、静音测试和主机回环均不代替真实服务或实体执行证据。

## 硬件待验的证据边界

- **部署与资源**：当前板卡的实际分区、安全状态、可恢复备份和匹配版本尚需部署前确认；当前修订的任务启动、堆/栈余量、低内存降级及长时间运行需实板观察。编译成功和镜像尺寸不证明运行资源充足。
- **APK 与无线控制**：真实 Android WebView、配对、无 PC 基础灯控、亮度 ACK/回读、倒计时、街机多键/释键、掉线与重连，以及触控至灯板反馈仍待验证。浏览器和 JVM 回环不能替代手机与 ESP32 联调。
- **正式无线音频**：板载麦克风 → Wi-Fi PCM → PC KWS/ASR/LLM/角色 TTS → Wi-Fi → 板载扬声器的完整轮次、连续对话、音量、断流恢复及音乐/音效优先级仍待实测。USB 诊断和本机生成 WAV 不替代该链路。
- **显示与供电表现**：既有布局/配色、亮度、Gamma、倒计时显示及提示音、世界线效果、音画时序仍以实体面板和用户听看反馈为准；没有新增 60 FPS、0% CPU、光学延迟或功耗测量结论。
- **视觉交互**：真实摄像头采集、登记/问候、手势抓投、视线校准及蛇/方块体感操作仍待用户场景验证；合成几何与训练点拟合不能代替独立准确率。

这些是待取得的整机证据，不是新的软件开发阶段。原历史 18 项中的品牌级描述、原生板载 WakeNet、Mem0、物理沙粒、原格式无损音乐及光学数字孪生，不能由当前替代实现或本轮回归改写为原样全部完成。
