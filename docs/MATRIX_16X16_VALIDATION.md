## 重现诊断

只有手动传入开关才会替换应用入口；诊断会持续循环，不能作为日常服务固件使用：

```powershell
cd firmware-s3
idf.py -DPRO_MATRIX_DIAGNOSTIC=ON build
# 确认观察者就绪后，手动烧录诊断固件。
idf.py -p COM9 flash
# 完成观察后，必须恢复完整应用并重新烧录。
idf.py -DPRO_MATRIX_DIAGNOSTIC=OFF build
idf.py -p COM9 flash
```

本次验证结束时构建缓存已恢复为 `PRO_MATRIX_DIAGNOSTIC=OFF`，板端运行完整正式应用。坐标检查可用 ESP32-S3 工具链执行：

```text
xtensa-esp32s3-elf-g++ -std=c++14 -fsyntax-only tests/matrix_layout_test.cpp
```
