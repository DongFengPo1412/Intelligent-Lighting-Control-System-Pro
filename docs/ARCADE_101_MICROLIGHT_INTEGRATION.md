## 二、 适配范围与硬件资源对齐说明

1. **严格 16×16 点阵矩阵渲染**：
   - 画面严格保持 256 颗 RGB LED 像素（768 字节/帧）。
   - 主角严格占用两颗像素：上方黄色头部 `(255, 230, 80)`、下方青蓝色身体 `(60, 190, 220)`。
   - 顶部右上角常驻生命条：红色表示剩余血量，暗红表示已损失血量。
2. **昼夜时钟与七大生态群落**：
   - 昼夜循环以 180 秒为周期，天空背景从日间天蓝 `(60, 160, 230)` 平滑过渡到暮色霞光 `(200, 90, 60)`，再到深邃夜空 `(12, 20, 40)` 并伴随星光闪烁。
   - 地图沿水平坐标展开七大生态群落（每 40 格切换）：草原（0）、森林（1）、湖泊（2）、沙漠（3）、雪原（4）、沼泽（5）、火山（6）。
3. **生存、挖掘与建造**：
   - A 键支持挖掘地表方块收集木材与石料，B 键支持搭建桥梁/设施与击退敌对生物。
   - 在火山生态中注意避开熔岩伤害；生命归零触发 GameOver；探索全部 7 大群落达成胜利。
4. **统一大厅全链路兼容**：
   - 在 ESP32 固件、Web 控制大厅、Android APK、手柄控制器及 UDP 直连中通过 `#101` 统一访问。
   - 完整保留原有 `#001`～`#100` 的所有卡带逻辑与存档，上限无缝扩充至 101。
