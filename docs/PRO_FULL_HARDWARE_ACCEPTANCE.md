## 二、 分阶段实机验收与缺陷闭环记录 (Stages B – F)

### 1. Stage B：32 种灯光模式与物理矩阵控制
- **实机验证**：模式 `0..31`（纯红/纯蓝/纯绿、幻彩霓虹、呼吸极光、流星、星空、全屏色彩、雨滴、波纹、笑脸/哭脸/爱心、沙漏倒计时、赛博烈焰、代码雨 Pro、指尖追踪、光球沙盒、世界线变动率、像素画布、音乐光环、环境微光等）全部通过真机点亮测试，亮度 `1..60` 线性可调。

### 2. Stage C：远场语音唤醒、双阶红灯防抖、青色思考灯提速、自然意象泛化与功放音质调优
- **防误唤醒与抗室友/室外杂音 (`59dddec`)**：
  - 唤醒词收敛为 5 个高辨识度发音（`红莉栖 / 牧濑红莉栖 / 克里斯蒂娜 / 阿玛迪斯 / 助手`，阈值 `0.46 / 1.5`）。
  - 唤醒后动态切换 `_asr_prompt()` 为简体中文曲库与游戏领域词提示（不含唤醒词与“结束对话”），并拦截 `avg_logprob < -0.95` 或含全角数字乱码的旁人杂音。
- **GPIO48 双阶段红色指示灯稳定防闪烁 (`59dddec`)**：
  - 说话期间保持稳定**亮红灯**（`dim_frames=22` 即 `0.66s` 抗音节间隙抖动，彻底消除说话时亮红/暗红频繁闪烁）；
  - 停顿满 `0.66s` 后转为**暗红灯**，再等待 `2.10s`（`silent_limit=92`）无后续语音才切入**青色思考灯 (`thinking`)**，支持任意长度的多分句完整表达（`max_frames=1000`）。
- **青色思考灯等待时间大幅缩短 (`HEAD`)**：
  - **高频自然意象与 101 款游戏零延迟辅助规划 (`< 1ms`)**：对常见自然意象（`森林/草原/西瓜/西兰花/抹茶 -> 绿灯(3)`、`大海/海洋/天空/晴空 -> 蓝灯(2)`、`夕阳/春联/红灯笼/玫瑰 -> 红灯(1)`、`晚霞/彩虹 -> 幻彩霓虹(4)`）及 101 款街机游戏建立带动作意图识别的快路径（严格区分动作指令 `"我想玩超级马里奥"` 与提问 `"超级马里奥是一款什么样的游戏？"`）；未预设的新奇意象仍走本地 LLM 语义推理。
  - **LLM 上下文精简与日文翻译错峰并发**：`SemanticControl.plan()` 精简至 13 组核心示例（`num_ctx=2048, num_predict=90`），`KurisuAgent._converse()` 限制生成长度（`num_predict=45`）；`VoiceEngine._speak_bilingual_stream()` 将首段中文拆分阈值降至 `22` 字，并**将 Ollama 日文翻译推迟至首段中文 TTS 合成完成之后再异步提交**，彻底消除首包 TTS 期间 Ollama 与 GPT-SoVITS 的 GPU 抢占，青色思考灯耗时由 `13~29s` 缩短至 **`3.5~5.5s`**。
- **室外演示扬声器音量提升与破音消除 (`HEAD`)**：
  - **音乐流 (`music_engine.py`)**：`DEFAULT_MUSIC_GAIN` 从 `0.25` 提升至 `0.55`（响度提升 `+6.8 dB`），高通滤波 `DEFAULT_MUSIC_HIGHPASS_HZ` 提升至 `155 Hz` 滤除小型喇叭腔体无法还原的低频振膜拍边破音，数字峰值限幅设为 `0.82`。
  - **语音流 (`voice_engine.py`)**：移除会导致金属伪影的 `noisereduce` 频谱减噪，采用 `135 Hz` 二阶高通 + `300 Hz` 减闷 (`-3.5 dB`) + `3.2 kHz` 人声穿透力增强 (`+2.5 dB`) + `7.2 kHz` 抗混叠低通 + `99.2%` 分位软限幅 (`0.84`)，人声响亮清晰。
- **点歌与游戏卡带 ASR 同音错字容错 (`HEAD`)**：
  - 点歌支持 `"跟我播放一首起理箱"` / `"播放一首七米香"` $\to$ `七里香`、`"播放米津玄师的莱蒙"` $\to$ `米津玄師 (よねづ けんし) - Lemon`、`"播放发如雪"` / `"播放青花瓷"`、`"播放第一手"` $\to$ `播放第一首`。
  - 游戏支持 `"我想完碳之蛇"` / `"我想玩攤吃蛇"` $\to$ `#033 贪吃蛇`、`"我想玩俄羅斯風範"` $\to$ `#041 俄罗斯方块`。

### 3. Stage D：双端视觉交互（手机前置摄像头 + 手机遥控电脑摄像头实时预览）
- **手机前置摄像头 (`9742d37`)**：默认 `270°` 正向旋转 + 水平镜像翻转 (`mirrored=True`)，画面上下正立，手部向左/右移动与 16×16 灯板光球向左/右移动完全同步。
- **手机端免配对码开启电脑摄像头与实时预览 (`9742d37`, `e20267a`)**：同局域网受信设备通过 `/api/status` 自动下发 `pairing_token`，无需手动输入配对码；修复 `MultimodalHub.start()` 启动标志与前端 `startPcCameraPreview()` Blob 预览流，手机端可实时查看电脑摄像头预览图并热切换指尖追踪、光球沙盒、情绪镜像、手势贪吃蛇。

### 4. Stage E & Stage F：音乐律动、101 款像素街机与像素涂鸦画布
- **曲库与街机**：本地 `2,236` 首曲目索引、频谱光效联动、101 款真实像素街机卡带（含 `#001 超级马里奥`、`#033 贪吃蛇`、`#041 俄罗斯方块`、`#101 微光纪元`）及手机横屏手柄全部实机验证通过。
- **像素画布与长期记忆**：16×16 实时像素涂鸦画布、预设图案下发与 SQLite 长期记忆闭环全部验证通过。
