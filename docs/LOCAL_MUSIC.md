# 本地曲库点歌

[English](LOCAL_MUSIC.en.md) · [日本語](LOCAL_MUSIC.ja.md) · [高阶控制台指南](PRO_FEATURES.md)

电脑读取原音乐文件，解码为 16 kHz 单声道 PCM，通过既有 Wi-Fi PCM 或 USB 音频路径交给板载扬声器。同一份 PCM 的 FFT 频带、RMS 和瞬态信息驱动音乐光环或 16 列频谱。无需增加 SD 卡，电脑必须保持运行并与灯板处于同一网络。

## 使用

1. 启动完整服务 `python -B pc-agent-vision/web_server.py`。沿用已有模型、KWS、角色语音与音频配置；Wi-Fi 音频使用 `KURISU_AUDIO_TRANSPORT=wifi`。
2. 打开 `http://localhost:8080/pro.html#musicLibrary`，在“电脑上的音乐文件夹”填写绝对路径，点击“保存并扫描”。目录保存在 `KURISU_DATA_DIR` 下，下一次启动自动扫描。
3. 按歌名、歌手或两者组合搜索，点击歌曲旁的“播放”。当前搜索结果构成播放列表，从选中歌曲开始；清空搜索可使用整个曲库。
4. 可用上一首、下一首、停止、顺序／随机、单曲／列表循环，播放时可切换光环和频谱。进度条只显示进度，暂不支持拖动或断点续播。

扫描优先读取歌曲自带的标题和歌手标签，缺失时使用文件名。仅索引受支持扩展名，不搬动、重命名或批量转换源文件。标签缓存位于 `KURISU_CACHE_DIR`，只在文件大小或修改时间变化时重新读取。歌曲在点播时解码，最大时长 30 分钟；本地曲库读取不受网页临时上传的 20 MiB 上限影响。

MP3、FLAC、WAV 等可由 SoundFile 解码；对安装环境不支持的格式使用现有 PyAV 解码后备路径，M4A/AAC 的实际可用性取决于安装的编解码器。并不宣称所有文件都已逐首验证。完整音乐仍为 16 kHz 单声道，不等于原素材无损或立体声。

## 语音

先说“助手”，等应答后点歌，例如：

- “播放周杰伦的七里香”／“我想听一首晴天”。
- “播放艾伦沃克的歌”按歌手建立播放列表。
- “下一首”“上一首”“停止音乐”。“暂停音乐”当前按停止处理，重新点播从头开始。
- “随机播放”“顺序播放”“单曲循环”“列表循环”“取消循环”。

歌曲名不唯一时不会任意播放，会列出候选；补充歌手、版本，或说“播放第 2 首”。当前语音点歌是有限的中文请求句式与本地目录匹配，不依赖模型虚构歌曲或执行任意文件路径；陌生外语歌名和识别错字可通过网页搜索补充。

歌曲开始本身作为声音确认，不再额外播放 TTS 抢占扬声器。网页文字聊天也走同一个点歌处理器。普通聊天会先停止当前音乐，避免回复与歌曲重叠。中文错字先按同音匹配，例如“周介伦、其理乡”；更大的发音偏差按歌手和歌名分别评分，仅在高分且明显唯一时自动播放，否则列出候选确认。常见歌手名会作为已唤醒状态下的识别拼写提示；不能据此承诺任意口音或外语歌名都能识别。

歌曲默认采用独立的 `0.25` 线性电平（约 −12 dB），仅作用于扬声器 PCM，不改变 MIR 分析源或助手音量。现场原电平被用户评价为严重失真，降低后评价为音效很好，因此选择该默认值；原音乐文件不被改写。

Wi-Fi 音频下默认允许歌曲播放时检测唤醒词：先说“助手”，声学关键词和无提示 ASR 确认后停止歌曲，再等待下一句；唤醒词后附带的指令也会交回正常指令流程。普通歌词不会直接进入控制转写。此路径使用参考音频处理，仍需现场评估不同歌曲、距离和音量下的误唤醒与漏唤醒，不能视为成熟声学 AEC。

`KURISU_MUSIC_WAKE=0` 可关闭音乐中的唤醒，保留网页切歌；USB 音频时不启用音乐唤醒。`--no-audio` 关闭自动语音／TTS，但网页仍可点歌并经板载扬声器播放。

## 配置与接口

| 配置 | 含义 |
| --- | --- |
| `KURISU_MUSIC_DIR` | 可选，覆盖已保存的曲库目录；不在源码中硬编码个人路径。 |
| `KURISU_DATA_DIR/music-library.json` | 已保存的目录配置。 |
| `KURISU_CACHE_DIR/music-library-tags.json` | 按大小／时间校验的歌曲标签缓存。 |
| `KURISU_MUSIC_WAKE` | 默认 `1`；仅完整语音服务、Wi-Fi 音频和 KWS／ASR 就绪时生效。 |
| `KURISU_MUSIC_GAIN` | 默认 `0.25`，范围 `(0,1]`；仅歌曲输出电平，修改后重启服务。 |

| 接口 | 请求 |
| --- | --- |
| `GET /api/pro/library?q=...&offset=0&limit=30` | 返回配置、扫描状态、总匹配数和分页歌曲，单页最多 100 首。 |
| `POST /api/pro/library` | `{"action":"configure","root":"绝对路径"}` 或 `{"action":"scan"}`。 |
| `POST /api/pro/music` | `{"track_id":"目录返回的ID","visual":"fluid","scope":"搜索词"}`；可选 `single:true` 只播放该曲。 |
| `POST /api/pro/music` | `{"query":"歌名或歌手"}` 查询并点播；有歧义时返回候选说明。 |
| `POST /api/pro/music` | `{"action":"next"}`、`previous`、`stop`；既有 `{"stop":true}` 仍支持。 |
| `POST /api/pro/music` | `{"action":"options","order":"shuffle","repeat":"all"}`；顺序可为 `sequential`，循环可为 `off/one/all`。 |
| `GET /api/pro/status` | `music` 包含当前歌曲、队列位置、时长／进度、扫描与错误状态、特征发送统计、音乐唤醒是否启用。 |

所有播放使用目录返回的 ID，再核对文件仍位于配置目录内。目录变化、歌曲移除、解码失败或设备未确认不会被报告为成功播放。停止和换歌会使旧队列的后续自动播放失效。

离线回归：`tests/test_music_library.py`、`tests/test_music_follow.py` 与 `scripts/test_interaction_regressions.py`。生成音频、日志和运行状态必须放在任务缓存；模拟接口不证明真实扬声器或声学唤醒效果。实机结果另见[验收记录](hardware-checks-20261023.zh-CN.md)。
