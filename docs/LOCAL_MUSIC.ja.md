# ローカル音楽ライブラリ

中国語の同音誤字はライブラリと照合します。より大きい発音差は歌手・曲名の高い一致度と候補間の差が必要で、それ以外は利用者が候補を選びます。起動後のみ頻出歌手名を綴りのヒントに使い、任意の発音・外国語認識を保証しません。音楽だけに既定で線形ゲイン `0.25`（約−12 dB）を適用します。利用者の比較試聴で選んだ値で、MIR解析源・助手音声には適用しません。`KURISU_MUSIC_GAIN`を`(0,1]`に設定して再起動すると変更できます。

[简体中文](LOCAL_MUSIC.md) · [English](LOCAL_MUSIC.en.md) · [Proガイド](PRO_FEATURES.ja.md)

PCが元ファイルを読み、選択曲を16 kHz・モノラルPCMへ変換して既存のWi-Fi PCM／USB経路で基板スピーカーに送ります。同じPCMのFFT帯域・RMS・onsetが光環／16列スペクトルを駆動します。SDカードの追加は不要ですが、PCと基板を同じネットワークで動作させてください。

`/#settings` でPC側の絶対フォルダーパスを保存・走査し、`/#music` で曲名や歌手を検索して再生します。旧 `/pro.html#musicLibrary` は統合音楽ページへ移動します。検索結果が再生リストとなり、検索を消すと全曲が対象です。前曲・次曲・停止、順番／シャッフル、曲／リストのリピートを選べます。進捗は表示のみで、シーク・途中再開は未実装です。

曲名・歌手タグを優先し、不足時はファイル名を使います。元ファイルの移動・一括変換は行いません。選択曲だけをデコードし、ローカル再生には20 MiBのアップロード制限は適用しません。曲は30分まで、出力は16 kHzモノラルです。SoundFileと既存PyAVの後備経路を使いますが、全ファイル／コーデックの動作を保証するものではありません。

音声操作は中国語で、起動語の後に `播放周杰伦的七里香`、歌手の曲群には `播放艾伦沃克的歌`、操作には `下一首`、`上一首`、`停止音乐`、`随机播放`、`顺序播放`、`单曲循环`、`列表循环`、`取消循环` を使います。同名曲が複数あれば候補を示し、`播放第2首` などで選びます。限定した要求文とローカル検索を使い、任意の言語理解を主張しません。暂停音乐は停止として扱い、再指定すると先頭から再生します。文字チャットも同じ経路です。曲の再生を応答とし、TTSの重複出力を避けます。

完全な音声サービスとWi-Fi音声では、音楽中も起動語を監視できます。声学KWSとヒントなしASRの両方で確認して曲を停止し、次の指示を待ちます。通常の歌詞は操作の書き起こしに直結しません。参照音声処理は完成した声学AECを意味せず、曲・距離・音量による誤起動や未検出は実機評価が必要です。`KURISU_MUSIC_WAKE=0` で無効化でき、USB再生では有効になりません。`--no-audio` は自動音声・TTSを無効にしますが、Webからの基板音楽再生は使えます。

設定は `KURISU_DATA_DIR/music-library.json`、タグキャッシュは `KURISU_CACHE_DIR/music-library-tags.json` に保存します。`KURISU_MUSIC_DIR` でフォルダーを上書き指定できます。個人パス・曲・生成音声・実行データをGitへ追加しないでください。

API:

- `GET /api/pro/library?q=...&offset=0&limit=30`：最大100曲のページ分割検索。
- `POST /api/pro/library`：`{"action":"configure","root":"絶対パス"}` または `{"action":"scan"}`。
- `POST /api/pro/music`：`track_id`、`visual:fluid|spectrum`、任意の検索範囲`scope`、任意の`single:true`。`query`で検索して再生することもできます。
- 操作は`action:next|previous|stop|options`、順序`order:sequential|shuffle`、リピート`repeat:off|one|all`。
- `GET /api/pro/status`：曲・キュー・進捗・エラー・走査・送信統計・音楽中の起動語監視状態。

ファイルはライブラリIDで選び、再生時も設定ディレクトリー内か確認します。停止・切替後は古いキューの自動継続を無効にします。離線試験は `tests/test_music_library.py` など、実機受入は[別記録](hardware-checks-20261023.ja.md)を参照してください。
