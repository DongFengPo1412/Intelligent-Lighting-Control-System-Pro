## 二、视觉设计系统与可访问性 (A11y) 审查

### 1. 色彩体系与对比度 (WCAG AA 达标)
- **背景主基调**：`#0c0808`（实验室暗室风格夜间底色），减少眩光并突出 WS2812B 绚烂光斑；
- **Amadeus 品牌红**：`#e83e8c` / `#d63384`，用于重要按钮、活动状态与红莉栖角色高光；
- **暖琥珀辅助色**：`#ffc107` / `#fd7e14`，用于世界线变动率、计时器与警告提示；
- **正文与辅助文本**：
  - 正文：`#f8f9fa`，对比度达 **14.2:1**（远超 WCAG 4.5:1 要求）；
  - 次级辅助文本：最低字号严格限制在 **12px** 以上，避免移动端字体过小导致阅读障碍。

### 2. 交互状态闭环与硬件 ACK 强关联
- **点击反馈**：所有按钮配置 `:active` 与 `:focus-visible` 动效；
- **真实设备确认**：严禁仅发送 HTTP 请求就单方面提示“操作成功”。界面操作后统一进入 Pending 旋转状态，只有收到硬件端回传包含 `status: ok` 或对应帧序列号的 ACK 报文后，才更新界面开关，保证“界面所见即板端实况”。

## 三、数字灯板 2D/3D 孪生预览引擎

1. **16×16 物理映射一致性**：
   - 严格遵循第 1 颗位于左下角、蛇形走线的硬件布局，Web 端的 2D Canvas 与 3D WebGL 模型与硬件 WS2812B 保持逐像素镜像；
2. **三维空间光影拟真**：
   - 3D 预览提供平滑轨道控制器（OrbitControls），具备抗锯齿与泛光（Bloom）着色器，真实模拟暗光环境下单个发光管的漫反射扩散效果。

## 四、Android APK 原生与 WebView 集成审计

1. **Native Bridge 权限与生命周期**：
   - 前置硬件相机桥接仅向经过验证的白名单源开启；
   - 切换至后台（`onPause`）或页面跳转（`onPageStarted`）时，立即释放底层 `Camera` 资源；
   - 引入会话标识校验 `stopFrontCamera(sessionId)`，避免过期异步消息干扰新会话。
2. **升级兼容性**：
   - Manifest 中 `versionCode=30`，`versionName="2.2.0"`；
   - 采用持久化官方签名密钥 `kurisu_release.keystore` 签名，保证现有用户直接无损覆盖升级，保留原有 WiFi 配置与偏好。
